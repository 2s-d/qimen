# API接口测试脚本使用说明

## 概述

`test_all_apis.py` 是一个完整的API测试脚本，用于测试所有18个接口是否能正常调用。

## 测试的接口列表

### 用户模块（4个）
1. POST /api/user/register - 用户注册
2. POST /api/user/login - 用户登录
3. GET /api/user/info - 获取用户信息
4. PUT /api/user/info - 修改用户信息

### 奇门模块（8个）
5. POST /api/qimen/calculate - 起盘计算
6. POST /api/qimen/save - 保存起盘记录
7. GET /api/qimen/history - 获取历史记录列表
8. GET /api/qimen/history/{id} - 获取历史记录详情
9. DELETE /api/qimen/history/{id} - 删除历史记录
10. GET /api/qimen/fortune - 获取今日运势
11. GET /api/qimen/tools/calendar - 获取万年历数据
12. GET /api/qimen/knowledge/articles - 获取知识文章

### 系统模块（6个）
13. GET /api/system/config - 获取系统配置
14. GET /api/system/help - 获取帮助文档
15. POST /api/system/feedback - 提交反馈
16. GET /api/system/announcements - 获取公告列表
17. GET /api/system/statistics - 获取统计数据
18. GET /api/system/health - 健康检查

## 使用方法

### 1. 确保后端服务正在运行

```bash
cd qimen-backend
python run.py
```

或者：

```bash
cd qimen-backend
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

### 2. 运行测试脚本

```bash
cd qimen-backend
python test_all_apis.py
```

### 3. 如果后端运行在不同端口

编辑 `test_all_apis.py`，修改 `BASE_URL`：

```python
BASE_URL = "http://localhost:3008"  # 改为你的端口
```

## 测试依赖

确保已安装 `requests` 库：

```bash
pip install requests
```

或者安装所有依赖：

```bash
pip install -r requirements.txt
```

## 注意事项

1. **测试顺序很重要**：脚本会按顺序执行测试，某些接口依赖前面的结果（如需要token的接口）
2. **自动创建测试数据**：脚本会自动创建测试用户和测试数据
3. **清理测试数据**：测试完成后，保存的记录会被删除
4. **超时设置**：每个请求的超时时间为10秒
5. **并发控制**：测试之间会有0.5秒延迟，避免请求过快

## 故障排查

### 连接失败
```
错误: 连接失败，请确保后端服务正在运行
```
**解决方法**：确保后端服务已启动，检查端口是否正确

### 认证失败
```
错误: 状态码错误: 期望 200, 实际 401
```
**解决方法**：检查JWT认证中间件是否正常工作

### 超时
```
错误: 请求超时（10秒）
```
**解决方法**：检查后端是否有性能问题，或增加超时时间

## 自定义测试

如果需要测试特定接口，可以修改 `main()` 函数中的 `tests` 列表：

```python
tests = [
    ("用户登录", test_user_login),
    ("起盘计算", test_qimen_calculate),
    # 只测试这两个接口
]
```

## 输出格式

测试脚本会输出：
- 每个接口的测试标题
- 测试结果（通过/失败）
- 详细信息（如返回的数据）
- 最终测试总结（总数、通过数、失败数、通过率）
